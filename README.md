# Зачётка — платформа подготовки к зачётам

Личный кабинет, вкладки с курсами, конспекты лекций по темам, интерактивные задания, тесты с подробным разбором ошибок и пробный зачёт.

## Что умеет

- **Личный кабинет**: имя, общий прогресс, «что повторить в первую очередь» (разделы с наибольшим числом ошибок), история пробных зачётов, резервная копия.
- **Курсы во вкладках.** Встроенный курс — «Разработка программного продукта» (8 тем).
- **Новый курс**: загрузи PDF лекций (или .txt/.md). Платформа отправит каждую лекцию в Claude и соберёт тему: конспект по шагам, разбор схем и формул, задания, 20–25 вопросов со ссылками на слайды. Нужен свой API-ключ Anthropic (вводится в профиле, хранится только в браузере).
- **Импорт курса из файла .json** — если курс подготовлен заранее (например, Claude сделал его в чате).
- **Разбор ошибок**: при неверном ответе сайт показывает правильный вариант, объяснение, ключевые определения и формулы нужного шага лекции и «где читать подробнее» (файл и номера слайдов). После теста — план повторения.

## Структура

```
index.html
css/style.css              — дизайн (белая основа, оранжевые акценты)
js/widgets.js              — интерактивные задания и калькуляторы
js/platform.js             — кабинет, курсы, темы, тесты, разбор ошибок, создание/импорт курсов
js/ai.js                   — генерация темы из лекции через Claude (официальный SDK, загружается только при генерации)
courses/product-dev/       — встроенный курс: course.js, topic1–8.js, slides.js (номера слайдов по шагам)
```

Данные пользователя (профиль, прогресс, собственные курсы) хранятся в браузере: localStorage и IndexedDB.

## Формат курса (.json для импорта)

```json
{
  "title": "Название предмета", "short": "Вкладка", "emoji": "📘",
  "exam": { "n": 24, "pass": 15 },
  "topics": [
    {
      "short": "Короткое имя", "title": "Название темы", "source": "lecture1.pdf",
      "summary": { "intro": "…", "points": ["…"] },
      "sections": [
        { "title": "Шаг", "slides": "3–7", "blocks": [
          { "type": "html", "html": "<p>…</p>" },
          { "type": "callout", "kind": "def|exam|warn|tip", "html": "…" },
          { "type": "scheme", "title": "…", "html": "…", "explain": "…" },
          { "type": "formula", "name": "…", "expr": "…", "parts": [["X", "что это"]], "why": "…", "example": "…" },
          { "type": "widget", "kind": "flashcards|classify|order|match", "title": "…" }
        ] }
      ],
      "cheatsheet": ["…"],
      "quiz": [ { "q": "…", "opts": ["…", "…", "…", "…"], "a": 0, "ref": 0, "hint": "…", "explain": "…", "why": { "1": "…" } } ]
    }
  ]
}
```

`ref` — индекс шага (с 0), где объясняется ответ; по нему строится разбор ошибки. HTML в импортированных курсах очищается от скриптов и опасных атрибутов.
